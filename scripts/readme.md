# scripts/

Scripts de automação, bootstrap, validação e apoio operacional.

## Categorias

| Pasta | Função |
|---|---|
| `bootstrap/` | Preparação inicial do ambiente/projeto |
| `validation/` | Checagens estruturais e auditoria |
| `automation/` | Tarefas repetíveis |
| `maintenance/` | Limpeza e reparo |

## Normas

Siga `rules-scripts.md` na raiz:

- descoberta da raiz do repositório;
- input numerado;
- `--uninstall` em scripts de instalação;
- equivalência Linux (`.sh`) / Windows (`.ps1`).
